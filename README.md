# Circle-In-Circle

Create Circle in a Circle (technically, it's an ellipse, but who cares).

## Description

This project is a simple web-based visualization tool that generates 2D circular data with Gaussian noise and displays it interactively using Plotly.

## Tech Stack

This project is built with:

* Python (Flask REST API) for the backend
* JavaScript (Plotly.js) for circle plotting
* HTML, CSS, and JavaScript for the frontend

## Guide

### Samples

Samples represent how many data points are generated in the plot.

* Few samples → the circle looks incomplete
* Many samples → the circle looks more defined

### Noise

Noise controls how much randomness is added to the data.

* Low noise → points stay close to the circle
* High noise → points spread out and distort the shape
